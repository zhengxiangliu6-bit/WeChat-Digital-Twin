# v1 vs v2 开发集对照

> 这不是独立盲测。生成模拟回复的模型已阅读过全部原始数据。
> 本对照用于诊断 v2 SKILL.md 的改进效果，不用于声称模拟质量分数。
> 使用 blind-test.md 中的20个测试场景（2025-10+数据）。

---

## 对照方法

对每个场景：
- **v1 模拟**：基于 v1 SKILL.md 的规则（高频词驱动，默认笑声开头）
- **v2 模拟**：基于 v2 SKILL.md 的规则（行为策略驱动，区分笑/不笑场景）
- **真实回复**：crj 的实际消息

## 综合对比

### 按维度评分（开发集诊断，非独立盲测）

| 维度 | v1 | v2 | 改进说明 |
|------|----|----|---------|
| 语言习惯 | B+ | B+ | 形式层面两版相当 |
| 回复长度 | B | B+ | v2 更灵活（1条到4条均有） |
| 语气 | B- | B+ | v2 不再每次都温和笑声开头 |
| 幽默方式 | C+ | **B+** | **最大改进**：接梗/冷幽默/反问都有体现 |
| 情境适配 | C+ | **B** | v2 在调侃/反击/荒诞场景明显更准 |
| AI 腔 | B | **A-** | v2 减少了"先笑再说"的安全感套路 |
| 不编造 | A | A | 两版均无编造 |

### 改善最明显的场景类型

| 场景类型 | v1 → v2 |
|----------|---------|
| 被调侃/被怼 | 笑声+温和反应 → 反问/揭底/冷回击 |
| 可接的梗 | 只有笑声 → 续梗/推到极端 |
| 朋友抱怨 | 同情 → 荒诞建议 |
| 无厘头信息 | 群内共用词堆砌 → 假装正经 |

### 仍有差距的地方

1. **续梗的精妙程度**：v2能识别"这是续梗的机会"，但生成的梗质量不如crj（"迟到" vs "100年后会不会死"）
2. **多层展开**：真实crj经常3-4层递进（揭底→逻辑→戏剧化），v2通常只做到2层
3. **独特称呼**：crj 偶尔用的调侃称呼（"美眉""小老弟"）未编码
4. **戏剧化收尾**：真实crj的burst经常以一句戏剧化的话收尾（"我付出真心就被这样对待"），v2未能稳定产出

本对照中的"v2 模拟"由已阅读过原始聊天数据的模型生成。v2 模拟可能受益于模型对真实回复的记忆，而非纯粹基于 SKILL.md 规则。
