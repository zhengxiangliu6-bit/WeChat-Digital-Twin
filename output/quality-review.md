## 5. 原有12组测试的数据泄漏审查

### 方法论问题

原有12组测试全部由**同一对话上下文**生成——生成SKILL.md的模型和生成"模拟回复"的模型共享记忆。这不是独立盲测。

### 逐条泄漏检查

| 测试 | 模拟回复来源 | 泄漏判定 |
|------|------------|---------|
| #1 搞笑事 | 虚构场景 | 无直接泄漏，但评价基于训练集比较 |
| #2 吐槽工作 | "怎么能工作到这种程度的"直接引自训练集(2025-04-15) | **训练集原话泄漏** |
| #3 搞笑图 | 虚构场景 | 无直接泄漏 |
| #4 冷场 | 虚构场景 | 无直接泄漏 |
| #5 惊讶消息 | 虚构场景 | 无直接泄漏 |
| **#6 恶作剧** | 模拟回复与测试集(2025-10-02)逐字匹配 | **测试集数据泄漏** |
| #7 旅行吃东西 | "等我回去打包给你们好了"引自训练集 | **训练集原话泄漏** |
| **#8 接梗** | 文档自认"这是训练集的原话" | **明确承认的训练集泄漏** |
| **#9 被调侃** | 模拟回复与测试集(2025-10-16)逐字匹配 | **测试集数据泄漏** |
| #10 游戏 | 虚构场景 | 无直接泄漏 |
| #11 无语 | 虚构场景 | 无直接泄漏 |
| **#12 被"杀"** | 模拟回复与测试集(2025-10-13)逐字匹配 | **测试集数据泄漏** |

**结论**：12组测试中有**4组直接复制了真实数据作为"模拟"结果**（#6、#8、#9、#12），另有2组混入训练集原话（#2、#7）。剩余6组虽然场景虚构，但由非独立模型生成，评价的中立性无法保证。

**这12组测试全部不能作为蒸馏质量的独立依据。**

### voice.md 中的测试集污染

voice.md 包含以下测试期数据（2025-10+）：

- 2025-10-02："我也是/五点半有人给我打电话/然后不出声/我直接挂了"
- 2025-10-13："完全精神病人/这个lzx的神经程度不在我之下"

**voice.md 应只包含训练集数据。测试期数据混入会在实际使用时造成循环引用。**
